# Publique — Brand Kit (SVG)

Editable vector assets for the Publique brand, based on the recent logo direction.

## Palette
- Signal Red: `#F10239`
- Paper Yellow: `#E3D898`
- Ink Black: `#181818`
- Soft Paper: `#F7F2E4`

## Files
- `publique-logo-horizontal.svg` — primary horizontal logo
- `publique-logo-stacked.svg` — stacked/vertical logo
- `publique-symbol.svg` — standalone symbol
- `publique-app-icon-light.svg` — light app icon
- `publique-app-icon-dark.svg` — dark app icon
- `publique-logo-monochrome.svg` — monochrome logo
- `publique-social-cover.svg` — social cover graphic

## Typography
The SVG wordmarks use `Inter` with Arial/Helvetica fallbacks. For closest fidelity, use Inter ExtraBold/800. Text remains live SVG text for easy editing; convert text to outlines before sending to a print vendor if required.

## Notes
- All assets are SVG and can be opened in Figma, Illustrator, Inkscape, or a code editor.
- The symbol and wordmark are a clean vector interpretation of the concept shown in the generated brand board, not a pixel-perfect extraction from the raster image.
